# Skills documentation

Two kinds of document live here, because "skills" means both things on this programme:

1. **Competency skills** (`SKL-nnn`, `skill-matrix.md`, `role-profiles.md`, `training-plan.md`, `hiring-guide.md`) — what people must know to build, implement and support the product, at which level, and how they get there.
2. **Practice skill cards** (`how-to-*.md`) — short, repeatable procedures for recurring engineering tasks on this codebase ("add a module", "author a rule", "add a report", "add a plugin", "write a migration"). These are the documents a new engineer follows to do the work correctly the first time.

Proficiency scale used throughout:

| Level | Meaning |
| --- | --- |
| 1 Aware | Can read and reason about it; needs supervision |
| 2 Working | Can complete standard tasks independently |
| 3 Proficient | Can design within the area, review others' work |
| 4 Expert | Sets direction, resolves novel problems, teaches |
