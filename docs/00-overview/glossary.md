# Glossary

| Term | Definition |
| --- | --- |
| Batch | A quantity of a product received together, sharing manufacture/expiry date, purchase cost and (optionally) MRP. |
| BOM | Bill of Materials — component list consumed to produce one unit of a manufactured item. |
| Counter | A physical POS station; one or more per store, each mapped to a cash drawer and printer. |
| Ledger | An account in the chart of accounts against which journal lines are posted. |
| Node | A deployment unit holding a local database: a standalone desktop, a store server, or the cloud tenant. |
| Outlet / Store | A physical location with its own stock and counters. |
| Payload-driven UI | Screens rendered at runtime from a JSON layout document rather than compiled FXML. |
| Plugin | An optional module packaged as a JAR implementing the plugin SPI, loaded at startup. |
| POS | Point of Sale — the billing screen and its hardware peripherals. |
| Rule | A Drools rule governing pricing, tax, discount, approval or validation, editable by authorized users. |
| Sync token | Monotonic per-node watermark used by the sync layer to request changes since last exchange. |
| Tenant | A business (single owner) whose data is isolated from other businesses in cloud mode. |
| UOM | Unit of Measure (piece, metre, kg, litre), with conversion factors per product. |
| Voucher | An accounting document (sale, purchase, payment, receipt, journal, contra, credit/debit note). |
